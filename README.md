# PRIMAL: First Fire

A hands-first VR science-survival game for the **Meta VR Start Developer Competition 2026** (Gaming · New Experience). You wake on the forest floor with nothing. Every machine is gone; the science isn't. Gather, build and experiment your way from bare hands to fire, charcoal and clean water.

Built with Meta's **Immersive Web SDK (IWSDK)** on three.js and WebXR, and shipped as a link (GitHub Pages). Design and plans live in [`docs/`](docs/): [DESIGN.md](docs/DESIGN.md), [PROJECT_STATUS.md](docs/PROJECT_STATUS.md), and the original browser prototype in [docs/prototype/](docs/prototype/README.md).

## Run it

Node 22.12+ (see `.nvmrc`).

```bash
npm install
```

```bash
npm run dev
```

`npm run dev` opens a managed browser with IWSDK's **IWER** emulator (an emulated Quest 3 in the browser). Click **Enter XR** to play in emulated VR; use the emulator's controls to move the headset, controllers or hands. Without entering XR you can also play on the desktop:

| Desktop | VR (hands or controllers) |
|---|---|
| `W A S D` / arrows walk, `Shift` run | Teleport (thumbstick, or hand micro-gesture swipe) |
| `Q` `E` or right-drag to look | Look around |
| Click to gather / place / use | Point and pinch (or trigger) |
| `Tab` satchel · `R` put back | Pinch the pouch on your hip |
| `H` hint · `N` notebook | HUD buttons on your left |

## How to play (Chapter 1, M1 slice)

1. **Wake up.** Quests say what you *need*, never where to find it. Ask for a hint; ask again for a clearer one, and a third time for a direction and a beacon.
2. **Gather** by pointing and pinching. Things fly into the satchel on your hip.
3. **Build** with snap-to-blueprint: take a key part out of the satchel (a stone for a fire pit, a flat slab for a workbench), point at open ground — a ghost outline follows you, green where you can build — and pinch to place it. Pinch each glowing snap spot to fill it.
4. **Craft** at a finished workbench: twist cord from fibres, then build the bow drill.
5. Every outcome is recorded in the **Lab Notebook** as Observation → Principle → Real-world limit. There are 31 to find; failures count too.

Progress saves in the browser automatically.

## Project layout

```
iwsdk.config.json          IWSDK project authority: scene, assets, XR features
src/game/                  pure game rules, no rendering: items, observations,
                           quests, hints, blueprints, world layout, save data
src/systems/               IWSDK ECS systems: gathering, building, satchel, HUD,
                           intro, world (fog/pause/autosave), desktop controls
src/scene-assets/          procedural low-poly forest, landmarks and item meshes
src/debug-hooks.ts         window.__primal: drive the game from the console
public/scenes/             scene composition (JSON)
public/ui/                 UIKitML panels (HUD, satchel, notebook card, tooltip)
tests/                     unit tests for src/game (vitest)
scripts/                   play-test and state scripts for the IWSDK CLI
docs/                      design, status, setup guides and the v3 prototype
```

## Checks

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm run build
```

End-to-end play-test against the running dev session (19 checks: gathering by real click, reach guard, blueprint placement and refusal, workbench, crafting, fire pit, hints, satchel, save/reload):

```bash
npx @iwsdk/cli dev up --allow-browser-automation
```

```bash
npx @iwsdk/cli browser run scripts/playtest.mjs --timeout 110000
```

`window.__primal` (see `src/debug-hooks.ts`) exposes `begin`, `goTo`, `face`, `gather`, `spots`, `take`, `place`, `fill`, `craft`, `hint`, `log`, `state` and `reset`. The event log (`__primal.log()`) is the thing to paste into a bug report.

## Deploy

Pushing to `main` runs [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml): typecheck, tests, build, then publish `dist/` to GitHub Pages. One-time setup: repository **Settings → Pages → Source: GitHub Actions**.

The project also contains IWSDK's agent guidance (`AGENTS.md`, `CLAUDE.md`, `.claude/`, `.agents/`, `.cursor/` …) generated by `npm create @iwsdk`.
